## 三网实测：移动 73ms，电信联通 189ms

这台国际线最低配的三网数据如下，来源是 2026 年 10 月 24 日的第三方测评。

| 运营商 | 平均延迟 | 去程路由 |
| --- | --- | --- |
| 移动 | 73ms | 上海出口 → 香港 → 马尼拉 |
| 电信 | 189ms | 上海出口 → 香港 → 马尼拉 |
| 联通 | 189ms | 北京出口 → 日本 → 香港 → 马尼拉 |
| 三网平均 | 144ms | — |

移动 73ms 这个数字放在菲律宾节点里算好看，原因是去程从上海出境后经香港直达马尼拉，跳数少。联通跑到 189ms，路由从北京出境，先绕日本再经香港，多出来的两段国际链路直接体现在延迟上。电信用的是同一条上海—香港—马尼拉的路径，延迟却和联通一样，问题出在稳定性上。

测评原文对稳定性的描述很直接：海外节点基本不丢包，国内节点里电信丢包比较严重，联通和移动还算稳定，结论是“电信网络大陆地区用户就不适合了”。测者本人用的是联通，本地 ping 平均 190ms，评价是“还算是比较稳定”。

189ms 的延迟能干什么，不能干什么，得分场景看。给菲律宾本地用户建的站，访问者根本不经过这条回国链路，189ms 与他们无关；做面向国内的 API、后台、远程开发环境，189ms 属于能用但手感一般；实时性要求高的场景（语音、游戏、长连接交互），这个延迟加上电信方向的丢包，体验会明显掉档。

## 优化线和国际线怎么选

两条线的配置长得几乎一样，差距全在路由上。优化线走 CN2、CMIN2 这类面向中国大陆的线路，官方对 Premium 的定义是 CN2 + 大陆 BGP + 国际 BGP；国际线走普通国际出口，从大陆访问可能绕路，但带宽给得宽、价格压得低。

价格上有个反直觉的地方值得说清楚：优化线的带宽档位反而更低。年付那台 VP01-A 是优化线，只给 5Mbps 不限流量；同价位的 VG01-A 是国际线，给到 10Mbps。多花的钱买的是回国路由质量，不是带宽。

给几条能直接用的判断规则：

- 访客主要在马尼拉或东南亚其他地方 → 国际线。$5/月那台 10Mbps 不限流量就够，回国慢不影响本地访问。
- 访客主要在中国大陆，且你那边是联通或移动宽带 → 优化线值这个差价。$7/月换 CN2/CMIN2，比国际线绕路稳定得多。
- 访客主要在中国大陆，你那边是电信宽带 → 两条线都别急。国际线的电信丢包有实测记录，优化线在电信方向的表现资料里没有独立实测数据，建议先买月付试一个月再决定要不要年付。
- 只是想有个菲律宾 IP 做注册、验证、测试 → 国际线最低配。带宽小不影响这类用途，$5/月的试错成本最低。

顺带一句参照：如果你的用户绝大部分在中国大陆，香港和台湾节点更合适。第三方测评提到香港机房国内 ping 能到 50ms 以内，台湾、香港的优化线月付也在 $5 到 $9 区间。选马尼拉的理由应该是“业务在菲律宾”，而不是“亚太节点里它最便宜”。

## 下单前必须知道的六件事

**1GB 内存装不了 Windows。** 官方口径是 2GB 内存以上的套餐才支持 Windows。$5/月那台 1GB 的最低配只能跑 Linux，想要 Windows 得直接上 $17/月 的 2核 2GB。有些测评写“支持安装 Windows”而不提内存门槛，容易让人误会。

**没有无理由退款。** 只有机器故障或服务问题导致无法使用时，才可以申请退款或换机。这一条对年付决策影响最大，先月付后年付不是谨慎，是必要。

**换 IP 第一次免费，之后 $2–5 一次。** IP 被墙或被滥用投诉封了，后续换 IP 是要花钱的。

**快照单独收费。** 不是套餐自带功能，需要额外购买。

**客服走英文工单，没有 7×24 在线客服。** 工单响应一般在几小时内，紧急问题可以走 Telegram。付款支持支付宝和 PayPal，信用卡也可以。

**开通时间分两种。** VPS 付款后 5–10 分钟自动开通，独服需要人工审核部署，12–24 小时。
